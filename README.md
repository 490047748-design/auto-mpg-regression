# Auto MPG Regression

使用 UCI Auto MPG 数据集训练线性回归模型，并通过 FastAPI 提供油耗预测服务。

## Project goals

- Use Git branches from feature to dev, staging, and main
- Track dataset versions with DVC and Azure Blob Storage
- Track model experiments with MLflow
- Serve predictions through FastAPI
- Test, lint, and build the project with GitHub Actions
- Package the application with Docker

## Planned workflow

feature/* → dev → staging → main
