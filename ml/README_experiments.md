# Auto MPG 实验总结

## 哪次运行适合供应用使用

本项目选择 improved-v2-linear-export，注册模型
AutoMPG_LinearRegression 的版本 6，作为后续应用使用的模型。
目前已完成导出，尚未部署服务。

所有方案从 v1 数据出发，使用相同的固定测试划分。
baseline 使用 313 条完整训练记录；
improved 使用 319 条训练记录，其中包括 6 条马力缺失记录。
测试集均为相同的 79 条马力完整记录。

| 实验 | CV RMSE | 测试 RMSE | 测试 MAE | 测试 R² |
|---|---:|---:|---:|---:|
| baseline-v1 | 未记录 | 3.2727 | 2.4198 | 0.7902 |
| improved-v2-linear | 3.367225 | 3.2691 | 2.4890 | 0.7906 |
| improved-v2-ridge-a01 | 3.367003 | 3.2699 | 2.4889 | 0.7905 |

| improved-v2-linear-export | 3.367225 | 3.2691 | 2.4890 | 0.7906 |

严格按平均 CV RMSE 排名，Ridge alpha=1 最低。
它相对 Linear 的差距仅约 0.00079 mpg。
本项目按简约原则选择不需要额外 alpha 参数的 Linear。

该取舍依据训练集交叉验证和模型复杂度，不依据测试集排名。
尚未进行统计显著性检验，不能由平均值接近断言统计等效。

improved 相比 baseline 能利用 6 条缺失马力的训练记录，
并将产地作为无序类别编码。
但测试 RMSE 只略有改善，MAE 反而略差，不能宣称全面优于 baseline。

## 优化的指标及其意义

主指标为训练集 5 折交叉验证的平均 RMSE，越小越好。
RMSE 的单位为 mpg，对较大的预测误差给予更大权重。

MAE 表示平均绝对误差，用于补充观察典型误差水平。
R² 衡量解释程度，不是分类准确率。

选择模型与 alpha 时使用训练集交叉验证。
固定测试集用于最终效果对照，不用于反复选择超参数。

## 评估边界与实验保存

测试集只包含马力完整的记录，因此当前测试结果不能单独证明
模型在所有缺失马力车辆上的实际预测效果。

本次 improved-v2 系列名称表示改进方案；
实际训练输入仍是 auto_mpg_v1.csv。
预处理统计量仅在训练数据上拟合，不直接使用全数据清洗后的 v2 CSV。

MLflow 使用本地 sqlite:///mlflow.db，制品保存在本机。
Git 推送不会自动把本地 MLflow 数据库和全部实验制品上传到 GitHub。
